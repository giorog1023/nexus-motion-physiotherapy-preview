Pass 2 V3 Visual Correction: Active Foreground Glass Only

In Pass 2 V2, an external review identified that while diagnostic high-contrast patterns transmitted through the card, the real 3D cervical spine collapsed into a flat, opaque pale-cyan panel (uniform Lum 70).

Root Cause Discovered & Resolved:
In Multiple Render Target (MRT) pipeline, `#drawbuffer WorkRefraction` was writing color * 0.40 on the front face. Because WorkRefraction feeds the refraction buffer tRefraction, the card was feedback-looping into its own refraction target each frame, crushing transmitted scene dynamic range. Decoupling #drawbuffer WorkRefraction gl_FragColor = vec4(0.0) immediately restored 100% optical transmission of the cervical vertebrae through the milky pearl-white frosted glass body. Pass 1 V19 typography remains 100% frozen (0.000px displacement, 0 edge bleed).
