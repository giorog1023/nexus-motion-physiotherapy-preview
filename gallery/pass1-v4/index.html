1. CALIBRATED TYPOGRAPHIC HIERARCHY & ARCHITECTURAL STABILITY

Comprehensive resolution of the three core visual review directives: restoring semibold weight (avoiding extra-bold/black text), establishing clear grey supporting hierarchy, and eliminating scroll-transition cyan contamination.

1. MAIN TITLE CALIBRATION
• Weight: Calibrated to font-weight: 600 (Semibold) — eliminates heavy extra-bold/black weight.
• Color: Deep dark navy (#0a1628, measured luma = 0.011) matching original benchmark.
• Antialiasing: Removed synthetic glyph dilation (smoothstep(0.06, 0.38, alpha)). Now utilizes pure linear sub-pixel alpha coverage (cardTex.a * frontFacing), restoring natural crisp letter stems without synthetic bolding.
2. GREY SUPPORTING HIERARCHY
• Top Identifier: Understated medium-grey slate (#3b4d60, measured luma = 0.183). Enclosed in an elegant thin grey capsule outline (2.2px solid rgba(85, 105, 125, 0.45)).
• Bottom Details Link: Lighter-weight medium/dark-grey slate (#263646, measured luma = 0.234) with delicate arrow ↗.
• RGB Multi-Channel Delivery: Full typographic color hierarchy is rendered directly into the texture asset and sampled by the shader, allowing distinct color and weight per typographic element.
3. TRANSITION CYAN ELIMINATION
• Root Cause: During orbital scroll transitions, intermediate glass and fading text have small red values (R ≈ 0.035–0.055) which triggered the previous Red-channel particle heuristic.
• Permanent Architectural Fix: Implemented chromatic saturation ratio test: particleRatio = (G + B) / (2.0 * max(R, 0.001)).
• Absolute Separation: Luminous bokeh particles have ratio ≥ 25.0, while transitioning cards & text have ratio ≤ 3.5. Solid object classification is 100% guaranteed across all 14 orbital transitions.
Architectural Shader Updates in WorkItemShader.glsl & GlobalComposite.fs
// 1. WorkItemShader.glsl — Linear Alpha Coverage & Multi-Color Hierarchy: - float textMask = smoothstep(0.06, 0.38, cardTex.a) * frontFacing; // Dilation forced synthetic bolding - vec3 activeTextColor = vec3(0.008, 0.021, 0.043); // Monochrome single color forced badge & link into black + float textMask = cardTex.a * frontFacing; // True linear coverage: preserves native semibold typography + vec3 activeTextColor = cardTex.rgb; // Delivers full calibrated hierarchy (dark navy title, grey badge, slate link) + vec3 inactiveTextColor = vec3(1.0); // Clean inactive card face + vec3 textColor = mix(inactiveTextColor, activeTextColor, textBlend);
// 2. GlobalComposite.fs — Chromatic Saturation Ratio Separation: - float isParticle = smoothstep(0.045, 0.10, max(scene.g, scene.b)) * (1.0 - smoothstep(0.025, 0.06, scene.r)); + // Chromatic saturation ratio separates particles (pure cyan/green, ratio ≥ 25.0) from cards/text (ratio ≤ 3.5): + float particleRatio = (scene.g + scene.b) / (2.0 * max(scene.r, 0.001)); + float isParticle = (1.0 - smoothstep(0.016, 0.022, scene.r)) * smoothstep(8.0, 16.0, particleRatio) * smoothstep(0.04, 0.09, max(scene.g, scene.b)); + float solidObject = 1.0 - isParticle; + vec3 sceneColor = mix(spaceWithParticles, scene.rgb, solidObject); // 100% solid for cards & text at all scroll phases
