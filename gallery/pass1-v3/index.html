Confirmed Root Cause: The Heuristic Inversion in GlobalComposite.fs

In Stage 5, GlobalComposite.fs introduced a heuristic to distinguish atmospheric bokeh particles from solid 3D meshes: float solidObject = smoothstep(0.03, 0.09, scene.r);. The author assumed that only particles had low red (R ≤ 0.02) and that all solid objects had R ≥ 0.08. However, the active card typography was calibrated to solid clinical dark navy (#02050b, where R = 0.008). Because R = 0.008 < 0.03, solidObject evaluated to 0.0! Consequently, GlobalComposite.fs treated the dark text as atmospheric space and additively composited the central cyan studio background (studioBg) directly over the text interior, turning the letters cyan. Along the antialiased perimeter of each glyph, as pixel values blended up toward the card body (R = 0.82) and crossed the 0.03–0.09 threshold, solidObject abruptly ramped to 1.0, shutting off the additive cyan studio background while the pixel was still dark — creating an inverted dark halo/outline around every letter!

// BEFORE (Pass 1 V2 - Flawed red-channel heuristic in GlobalComposite.fs): - float solidObject = smoothstep(0.03, 0.09, scene.r); // FAILS: Dark navy text (#02050b) has scene.r = 0.008 < 0.03! - vec3 spaceWithParticles = studioBg + scene.rgb; - vec3 sceneColor = mix(spaceWithParticles, scene.rgb, solidObject); // Adds cyan studioBg directly into text interior! // AFTER (Pass 1 V3 - Physically accurate chromaticity/luminance classification): + // Atmospheric bokeh particles are luminous emissive cyan/mint (high green/blue > 0.045, low red < 0.025) + // Dark typography (#02050b) is dark absorbing pigment (max(G,B) <= 0.045) and must NEVER be treated as additive particles + float isParticle = smoothstep(0.045, 0.10, max(scene.g, scene.b)) * (1.0 - smoothstep(0.025, 0.06, scene.r)); + float solidObject = 1.0 - isParticle; + vec3 sceneColor = mix(spaceWithParticles, scene.rgb, solidObject); // Text is 100% solid, zero studioBg added!
// WorkItemShader.glsl Typography Compositing Cleanup: - vec3 textLayer = mix(cleanBaseSurface, textColor, textMask); - vec3 color = mix(finalGlass, textLayer, textMask); // Double-mix applied textMask twice (T^2), crushing edge AA + // Crisp linear alpha blend of typography directly onto polished glass surface + vec3 color = mix(finalGlass, textColor, textMask); // Pure linear blend: #02050b text, razor-sharp edges
